# Changelog

## 2026-10-19 — Initial showcase edition

Prepared a curated, local-first portfolio edition with the application source, application tests, SQL examples, synthetic backup fixtures, and a compact governance package. Private operating records and cloud operation launchers are excluded. Browser storage uses a separate showcase namespace.

The portfolio documentation explains human product direction, bounded agent implementation, recovery and provider controls, and evidence limits. This date records showcase preparation, not the start or duration of the underlying application's development. Publication and validation status are tracked in [the plan](docs/PLAN.md) and [verification record](docs/VALIDATION.md).

Compatible security updates bring Next.js and its ESLint configuration to 16.3.8, Sharp to 0.35.5, and affected transitive packages to patched versions. The independent checkout passed 772 tests with one database integration test skipped, lint/type checks, three offline fixture planners, and the build. The remaining unpatched development-tool advisory and bounded source review are recorded in [VALIDATION.md](docs/VALIDATION.md). No cloud deployment accompanies this edition.
